เช้าให้ Claude ช่วยเขียนโพสต์ขายกาแฟ
บ่ายให้ช่วยทำคอนเทนต์สอน AI
แล้วเราควรแยกงานพวกนี้ยังไงดี?

ถ้ามีหลายงานที่ต้องกลับมาทำเรื่อย ๆ ลองจัดเป็น Projects ดูครับ

นึกภาพว่าแต่ละ Project เป็นพื้นที่ทำงานหนึ่งชุด มีทั้งไฟล์อ้างอิง แนวทางให้ Claude ตอบ และแชตที่เกี่ยวข้อง ช่วยให้เราเลือกบริบทให้ตรงกับงานได้ง่ายขึ้น

อย่างงานร้านกาแฟ อาจมีข้อมูลสินค้า วิธีชง กลุ่มลูกค้า และแนวทางการขาย พร้อมคำสั่งว่า…

“ช่วยงานร้านกาแฟโดยยึดข้อมูลสินค้าที่ให้ ถ้าไม่มีราคา หรือโปรโมชัน ให้ถามก่อน อย่าแต่งขึ้นเอง”

ส่วนงานช่องคอนเทนต์ ก็แยกอีก Project เก็บกลุ่มคนดู ตัวอย่างโพสต์ และกติกาของช่อง เช่น…

“ช่วยทำสื่อสอน AI สำหรับมือใหม่ ใช้ภาษาไทยเข้าใจง่าย ยกตัวอย่างงานจริง และบอกเมื่อข้อมูลยังไม่แน่ใจ”

แล้วต้องสร้าง Project ใหม่ทุกโพสต์ไหม?

ไม่จำเป็นครับ ถ้ายังใช้ข้อมูลหลักและแนวทางเดียวกัน ก็แยกเป็นแชตย่อยใน Project เดิมได้ เช่น แชตเขียนโพสต์สินค้า กับแชตตอบคำถามลูกค้า

ลองใช้เกณฑ์ง่าย ๆ ว่า เป้าหมายต่างไหม ข้อมูลที่ต้องใช้ต่างไหม และน้ำเสียงต่างกันหรือเปล่า ถ้าต่างกันมาก การแยก Project ก็ช่วยให้จัดงานง่ายขึ้น

แต่มีจุดที่ควรจำไว้ด้วยนะครับ

ตั้งชื่อ Project อย่างเดียว ยังไม่พอจะอธิบายงานทั้งหมดให้ Claude เข้าใจ ควรใส่บริบทในคำสั่งหรือไฟล์อ้างอิงด้วย และอย่าคาดว่าแชตใหม่จะรู้ทุกอย่างจากแชตเก่า

ข้อมูลเปลี่ยนก็ต้องอัปเดต เช่น ราคาสินค้าใหม่ หรือกติกาช่องที่เปลี่ยนไป รวมถึงตรวจการตั้งค่า Memory และสิทธิ์แชร์ให้เหมาะกับงานด้วย

วันนี้ลองเลือกงานสองชุดที่ทำบ่อย แล้วแยก Project พร้อมใส่ไฟล์หลักกับแนวทางตอบสั้น ๆ ก่อนก็ได้ ไม่ต้องจัดทุกอย่างให้สมบูรณ์ตั้งแต่วันแรก

เลื่อนดูทั้ง 7 ภาพ แล้วคัดลอกข้อความในภาพสุดท้ายไปลองใช้ได้เลยครับ
